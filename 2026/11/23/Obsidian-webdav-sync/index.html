Obsidian与cloudflare后的webdav同步服务的设置

简介

本人需要在Windows PC和安卓手机之间进行obsidian vault的同步，同步服务使用的是个人的国外VPS里搭建的nginx webdav服务。由于使用的非标准HTTPS端口，导致obsidian检查webdav自建证书失败，故考虑使用cloudflare的tunnel机制将端口映射为公网的标准HTTPS端口。

安装Cloudflared

dnf config-manager --add-repo https://pkg.cloudflare.com/cloudflared.repo
dnf install -y cloudflared

配置Cloudflare tunnel

cloudflared tunnel login

cloudflared tunnel create <Tunnel Name>
该命令会创建一个Tunnel ID。Tunnel Name最终可以在Cloudflare DNS Record里查询到。

编辑cloudflared配置文件

vi ~/.cloudflared/config.yml，内容如下：
tunnel: <Tunnel ID>
credentials-file: /root/.cloudflared/<Tunnel ID>.json
ingress:

  • hostname: Domain
    service: https://localhost:Port
    originRequest:
    noTLSVerify: true
  • service: http_status:404

设置Cloudflare的DNS Record

cloudflared tunnel route dns Tunnel Name Domain

安装Cloudflared服务

cloudflared service install
systemctl start cloudflared
systemctl enable cloudflared
